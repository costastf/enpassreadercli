============
Installation
============

At the command line::

    $ pip install enpassreadercli

Or, if you have virtualenvwrapper installed::

    $ mkvirtualenv enpassreadercli
    $ pip install enpassreadercli

Or, if you are using pipenv::

    $ pipenv install enpassreadercli

Or, if you are using pipx::

    $ pipx install enpassreadercli

The SQLCipher dependency is provided by sqlcipher3, which ships prebuilt wheels with SQLCipher
bundled for Linux, macOS and Windows, so no compiler or system SQLCipher library is needed.
